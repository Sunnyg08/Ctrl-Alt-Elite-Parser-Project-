----------------------------------------
MEMBER 3 – TREVOR
----------------------------------------

Implement conditional statements and Python indentation.

Required statements:
- if
- elif
- else

The grammar must recognize indented blocks containing multiple statements.

Example:

if x > 5:
    y = 10
    z = 20
else:
    y = 0

The existing grammar skips whitespace, so indentation handling needs to be updated.

Use INDENT and DEDENT tokens or another appropriate ANTLR4 solution.

Make sure the lexer handles the tabs used in the professor's sample.

Also support multiple elif branches and nested conditional statements for generalization.

Coordinate with Wesley because the conditional statements use his expression rules.

----------------------------------------
HOW TO TEST ON MAC
----------------------------------------

Generate:

antlr LightPython.g4

Compile (Homebrew ANTLR 4.13.2 installation):

javac -cp "/opt/homebrew/Cellar/antlr/4.13.2/antlr-4.13.2-complete.jar:." LightPython*.java

Test:

java -cp "/opt/homebrew/Cellar/antlr/4.13.2/antlr-4.13.2-complete.jar:." org.antlr.v4.gui.TestRig LightPython program -tree project_deliverable_2.py

Display visual parse tree:

java -cp "/opt/homebrew/Cellar/antlr/4.13.2/antlr-4.13.2-complete.jar:." org.antlr.v4.gui.TestRig LightPython program -gui project_deliverable_2.py

Commands may differ on Windows or Linux.
