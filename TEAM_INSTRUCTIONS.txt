3. MEMBER 2 – ARITHMETIC AND OPERATORS
==================================================

Member 2 is responsible for adding arithmetic expression rules to `LightPython.g4`.

TASK A: Arithmetic Operations

Support the following operators:

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Modulo (%)

Examples:

    x = 1 + 2
    y = 13 - 3
    z = 4.2 * 10
    result = 10 / x
    remainder = 10 % 3

TASK B: Compound Assignments

Support the following:

    x += 5
    x -= 3
    x *= 2
    x /= 4

TASK C: Negative Numbers and Generalization

The grammar should also recognize:

    x = -1000
    y = 666
    result = -x + 5

TASK D: Operator Precedence

Implement the correct order of arithmetic operations.

For example:

    result = 2 + 3 * 4
    result = (2 + 3) * 4

Multiplication and division must have higher precedence than addition and subtraction.

Once completed, test these rules before merging changes.

==================================================
6. HOW TO RUN AND TEST THE PARSER
==================================================

The initial setup was tested on macOS using ANTLR4 version 4.13.2 and Java.

STEP 1: Open Terminal and navigate to the project folder.

STEP 2: Generate the parser.

    antlr LightPython.g4

This creates the Java parser and lexer files automatically.

STEP 3: Compile the generated files.

For the macOS Homebrew installation used during initial testing:

    javac -cp "/opt/homebrew/Cellar/antlr/4.13.2/antlr-4.13.2-complete.jar:." LightPython*.java

If no errors appear, compilation was successful.

NOTE: The ANTLR JAR path may be different on other computers.

STEP 4: Test the professor's sample file.

    java -cp "/opt/homebrew/Cellar/antlr/4.13.2/antlr-4.13.2-complete.jar:." org.antlr.v4.gui.TestRig LightPython program -tree project_deliverable_1.py

This prints the parse tree in Terminal.

STEP 5: Check the results.

A successful test should:

- Generate a parse tree.
- Recognize all 21 assignment statements.
- Report no lexer or syntax errors.
- Consume the entire input file.

IMPORTANT: ANTLR may still print a parse tree even when errors occur. Check the Terminal output carefully.

If the grammar reports errors, identify the failing statements, update the grammar, and repeat the test.
